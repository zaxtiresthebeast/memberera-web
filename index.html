Getting Started

How It Works

Get free members for your server in three simple steps.

1

Type !authlink

Head to the #authorize channel in our Discord server and type the command. The bot will send you an authorization link.

2

Authorize Your Account

Click the link and authorize your Discord account. You'll get an authorization key — copy it and paste it back with !auth <key>.

3

Run !order <server_id>

Go to the farm channel and run the order command with your server ID. Sit back and watch members join.
